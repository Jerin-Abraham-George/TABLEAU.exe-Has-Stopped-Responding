# 🎌 Anime Dashboard | Tableau

## 📘 Overview
The **Anime Dashboard** is an interactive **Tableau** project built to explore and analyze one of the largest anime datasets. It provides insights into anime popularity, ratings, audience engagement, production details, and content characteristics through an intuitive and visually engaging dashboard.

The project enables users to compare anime based on ratings, popularity, members, favorites, genres, studios, producers, licensors, source material, and more. It also offers a dedicated profile page for every anime title, making it useful for anime enthusiasts, researchers, and data analysts alike.

---

## 🎯 Objectives
- Analyze the overall anime landscape across multiple dimensions.
- Identify the highest-rated and most popular anime.
- Explore relationships between ratings, popularity, and audience engagement.
- Compare anime by genre, type, source material, producers, and licensors.
- Provide detailed information for individual anime titles.
- Enable interactive filtering for customized analysis.

# 🗂️ Dashboard Structure

The Tableau workbook consists of **three interactive dashboards**.

---

## 📊 1. Overview Dashboard

Provides a high-level summary of the complete anime dataset.

### Key Insights

- Total Anime Count
- Average Rating
- Average Episode Duration
- Average Number of Users Rating an Anime
- Anime Distribution by Source Material
- Anime Distribution by Status
- Anime Distribution by Type
- Scatter Plot showing Rating vs Users Scored
- Interactive filtering across multiple attributes

---

## 🏆 2. Score vs Rank Dashboard

Designed to compare the highest-ranked anime based on multiple popularity metrics.

### Includes

- Top N Anime Selector
- Rank vs Score comparison
- Total Members
- Average Rating
- Favorites Count
- Interactive filters by:
  - Genre
  - Type
  - Licensor
  - Producer
  - Source
  - Rating

This dashboard helps identify anime that are not only critically acclaimed but also widely popular among viewers.

---

## 🎥 3. Anime Details Dashboard

Provides a dedicated profile page for each anime.

### Displays

- Anime Synopsis
- Cover Poster
- Genres
- Producers
- Global Rank
- Average Rating
- Users Rated
- Favorites
- Episode Count
- Runtime
- Age Rating
- Overall Audience Attention

Users can instantly switch between anime using the title selector to explore detailed information for any show.
